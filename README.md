# SnapSyntaxProject
KAMUI is a minimalist portfolio-style webpage designed using HTML, CSS, and JavaScript. The website focuses on a clean layout, simple animation, and scroll-based interaction. It demonstrates how basic web technologies can be used to create an interactive visual experience.

The homepage contains a centered rectangular frame that visually splits the word KAMUI into two parts: KAM outside the rectangle and UI inside it. A black animated box interacts with the layout and moves across the page when the user scrolls.
